# Badge Studio CLI build receipt

September 17, 2026. Defined contract: versioned local badge documents shared with the existing editor. Built for source use today and a Node 22-compatible package later; package publication remains pending.

Four command paths cover catalog listing, schema inspection, new-document creation and validation. The binary was built, linked with Bun and invoked as `badge-studio`, including a real TTY. Non-TTY help, version, catalog, creation, validation and error envelopes were exercised with Node. All 17 presets were written and validated. Existing files and symlinks were refused; dry run did not write.

Presentation adapts the inspected cligentic detect, style and banner patterns. No runtime dependency, credential flow, remote operation, audit system or confirmation prompt is introduced. Detailed adoption decisions live in `friction.md`.

A CLI-created document was imported through the web editor. An invalid import preserved the existing design and displayed an error. A thermal portrait was changed to silver through the inspector, restored, saved and reloaded. All three physical originals exported both faces from WebGPU; their reverse QR codes decoded from the resulting previews.

The complete local suite passed 84 tests and 1,805 assertions. Web, schema, renderer and CLI builds passed, along with TypeScript and Biome. The landing's real pointer drag, inertia, keyboard, audio start/mute, gallery filter and mobile width were exercised. Reduced motion kept its angle unchanged. Axe reported zero WCAG 2 A/AA violations in the inspected light landing.

A production build initially interfered with the running development instance because both used `.next`. Development now uses `.next-dev`. This preserves a usable local preview during subsequent build checks.

These checks cover a local studio. They do not prove arbitrary prompt quality, a hosted multi-tenant service, broad device coverage or npm distribution. Visual review was performed sequentially without a separate reviewer.
