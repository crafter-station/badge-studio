# Source provenance

Badge Studio was extracted on September 17, 2026 from `crafter-station/event-sdk`, branch `codex/living-prism-badges`, with repository HEAD `7541639c0635cf387fa171c875f0618882c17331` and additional local badge editor work. The HEAD alone does not contain the entire extracted implementation.

The extraction includes the badge document model, the Prism/WebGPU renderer, the design editor and its local API. It does not include the event platform, registration flows or unrelated Event SDK work. The original repository is retained.

Badge Studio adds its own landing, shared serialized catalog, local CLI, JSON import and toolkit documentation.

The nine event styles are interpretations of their respective art directions, including references supplied by the project owner. Their presence is not an endorsement or a claim of ownership over event brands.

The renderer originated from the earlier Prism work, informed by the open source Vercel Labs vgpu.sh implementation. Preserve existing attribution and asset licenses.

The source AGPL-3.0-only license is retained. Fonts under `apps/web/public/prism/andes` and `apps/web/public/prism/next-craft` retain their individual licenses.
